# chalvinwz/homebrew-tap

Homebrew formulae for tools by [chalvinwz](https://github.com/chalvinwz).

## Usage

```sh
brew install chalvinwz/tap/<formula>
```

Homebrew adds the tap automatically the first time. Update with `brew upgrade`.

## Formulae

| Formula | Description |
| ------- | ----------- |
| [lazyssm](https://github.com/chalvinwz/lazyssm) | Terminal UI for AWS SSM Session Manager |

Each project has one file in `Formula/`. Formulae are updated by each project's
release workflow; changes made here by hand are overwritten on the next release.
